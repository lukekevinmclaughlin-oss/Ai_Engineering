Ai_Engineering requires no account or login.

On first launch, the subscription screen appears. Use the sandbox purchase sheet to begin the 14-day introductory trial for the platform-specific Ai_Engineering Pro Monthly subscription. The Restore Purchases control is directly below the main purchase button.

After entitlement verification, all five main sections are available: Home, Learn, Tutor, Projects, and Progress. Tutor Core works offline and does not require an external API key. Optional external providers are disabled by default and are not needed for review.

The subscription provides ongoing access to 40 courses, 400 interactive lessons, 140 editable code labs, 40 portfolio projects, validation, project workspaces, Tutor Core, and learning-progress features across the user's devices.

No special hardware, test account, or external service is required.
